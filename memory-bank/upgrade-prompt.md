📋 مشروع: إعادة تصميم وتطوير تطبيق إدارة مخزون وحدة القسطرة القلبية (Cath Lab Inventory System) – Mobile-First Web App

---

### 1️⃣ الهدف الأساسي
- إعادة بناء Web App لإدارة مستلزمات وحدة القسطرة القلبية (Stents, Balloons, Catheters)
- Mobile-First: تجربة سلسة على الموبايل قبل الشاشات الكبيرة
- سريع وسهل الاستخدام، مع الحفاظ على المنطق الحالي للنظام
- Web App على Cloudflare Pages وبيانات على Cloudflare D1

---

### 2️⃣ المستخدمون وصلاحياتهم

- **أنت – Admin / Expert**
  - إدخال أصناف جديدة ومشتريات
  - إدارة الباقات وتحديد مكوناتها
  - متابعة المخازن، الاستهلاك، التقارير والتنبيهات
  - ضبط إعدادات الموردين ومدة الاستبدال لكل مورد
  - صلاحيات كاملة (Full Access)

- **مسؤول المخزن – Operational User**
  - تسجيل تحويلات المخزون للمخزن الفرعي (غرفة العمليات)
  - تسجيل استهلاك الأصناف بعد العمليات
  - مراجعة الكميات، تواريخ الصلاحية، حد الطلب
  - لا يرى الأسعار، لا يعدل الباقات أو الأصناف
  - صلاحيات Read + Execute فقط

---

### 3️⃣ Workflow / دورة العمل

1. **تحويل المخزون**
   - المخزن الرئيسي → مخزن العمليات
   - لا يسمح بالصرف إذا الرصيد غير كافي

2. **تسجيل الاستهلاك**
   - اختيار باقة أساسية → زر واحد → خصم تلقائي
   - عرض بصري لمكونات الباقة للمراجعة فقط
   - أصناف إضافية → Scan → يظهر اسم الصنف + المتغير + Expiry → زر موافق

3. **إدخال المخزون والمشتريات الجديدة**
   - Scan Barcode:
     - إذا الصنف موجود → النظام يتعرف عليه → Admin يحدد الكمية والسعر
     - إذا الصنف جديد → Admin يضيف البيانات يدويًا (الاسم، النوع، Variant، السعر، الكمية)
   - أي صنف جديد يصبح متاحًا لجميع المستخدمين، الباقات، Dashboard وVariant Picker

4. **Barcode Smart System**
   - Hybrid:
     - صنف معروف → تعبئة تلقائية
     - صنف جديد → إدخال مرة واحدة → يتعلم النظام للتكرار
   - كل Scan → إضافة صنف → التطبيق يتكفل بالتجميع والترصيد

5. **Variant Picker**
   - Hybrid: أزرار للخيارات الأساسية + Dropdown للخيارات التفصيلية
   - مرتبط بنوع الصنف
   - أمثلة:
     - القسطرة التشخيصية: JR, JL, AL, AR | أحجام: 3.5, 4, 4.5, 5, 1, 2
     - الدعامات: أقطار: 2.50, 2.75, 3.00, 3.50 | طول: 18, 22, 26, 30, 34, 38, 48

6. **Feedback بعد Scan**
   - نجاح → عرض اسم الصنف + Variant + Expiry → زر موافق
   - خطأ → يظهر تحذير بسيط
   - لا حاجة لأصوات متعددة أو اهتزازات

7. **الباقات (Packages)**
   - مرنة → Admin يحدد مكوناتها
   - مسؤول المخزن يستخدم زر واحد → خصم تلقائي
   - عرض المكونات بصريًا فقط للمراجعة

8. **التقارير وDashboard**
   - Hybrid Dashboard:
     - مسؤول المخزن → Dashboard مبسط (رصيد، Expiry، حد الطلب)
     - Admin → Dashboard كامل (رصيد كل المخازن، الاستهلاك اليومي/الشهري، الأصناف الأكثر استخدامًا، إدارة الباقات)
   - Hybrid Alerts:
     - Alerts فورية عند الحاجة الحرجة (Expiry قريب جدًا، حد الطلب)
     - تنبيهات عادية تظهر في Dashboard فقط

9. **تنبيهات اقتراب انتهاء الصلاحية حسب الموردين**
   - كل صنف مرتبط بـ Supplier
   - لكل Supplier → تحديد مدة الاستبدال المسموح قبل انتهاء الصلاحية
   - إذا تبقى أقل من مدة الاستبدال → تنبيه Admin:
     - اسم الصنف
     - تاريخ الصلاحية
     - المورد
     - المخزن الحالي
     - المدة المتبقية قبل تاريخ الاستبدال
   - Admin قادر على تعديل مدة الاستبدال لكل مورد

10. **قواعد المخزون**
    - لا صرف بدون رصيد كافي
    - حد الطلب → تنبيه قبل النفاد
    - كل الأصناف لها باركود فريد → يقلل تكرار الأخطاء

### 4️⃣ UI / UX

- Mobile-First & Thumb-Friendly:
  - Cards ذكية + Swipe Actions للتعديل/الحذف
  - Bottom Sheets بدلاً من Modals
  - Bottom Navigation Bar للوصول السريع للوظائف

- Visual Variant Picker:
  - Buttons + Dropdown
  - ألوان مميزة للتمييز

- Dark / Light Mode:
  - الوضع الليلي والنهاري كامل لكل المستخدمين

- Animations:
  - Moderate, جذابة وأنيقة
  - لتأكيد الإضافة، اختيار Variant، نجاح Scan

---

### 5️⃣ Tech Stack

- Frontend: React (Next.js) Web App
- CSS / UI: TailwindCSS + Shadcn/ui أو Radix UI
- State Management: React Query (TanStack Query)
- Database: Cloudflare D1
- Hosting: Cloudflare Pages
- Optional: PWA لاحقًا

---

### 6️⃣ إضافات وملاحظات

- Hybrid System لكل Alerts, Dashboard, Barcode Handling
- المسؤول التنفيذي لا يحتاج معرفة بالأسعار
- التركيز على السرعة + الدقة + تقليل الأخطاء البشرية
- إدخال مستلزمات جديدة ومشتريات بالكامل تحت إشراف Admin
- إعدادات لكل صنف تحدد المتغيرات الأساسية والثانوية مسبقًا
- Mobile-First UX، سريع، سلس، جذاب
