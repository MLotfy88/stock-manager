# Integrations

## External Services
- **Supabase**: Primary database and authentication provider.
- **Capacitor**: Mobile native bridging (Camera API used for barcode scanning).

## Hardware & Local
- **HTML5 Web QrCode / React-Webcam**: Used for barcode scanning directly in browser.
- **IndexedDB (via Dexie)**: Local offline storage.

## Data Processing
- **Papaparse**: CSV ingestion/export.
- **xlsx**: Excel spreadsheet ingestion/export.
