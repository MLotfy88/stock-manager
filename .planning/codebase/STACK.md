# Tech Stack

## Frontend Runtime
- React 18 (DOM)
- TypeScript

## Build Tooling
- Vite

## UI & Styling
- Tailwind CSS
- shadcn/ui components (Radix UI primitives)
- Lucide React (Icons)
- Framer Motion

## State & Data Handling
- React Query (server state & caching)
- React Hook Form + Zod (forms & validation)

## Mobile & Cross-platform
- Capacitor CLI & Core/Camera/Android plugins

## Backend & Database
- Supabase (Backend-as-a-service provider)
- Dexie (IndexedDB wrapper for local DB / offline support)

## Tooling
- ESLint
- PostCSS
